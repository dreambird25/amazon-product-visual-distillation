# 多模态版型与符号复测协议

## 先核对抽取图

- **版型图对照原图/刀模**：物件类别和件数、实体裁切/折叠轮廓、长宽比例、材质纹理、底色/边带、印花区位置是否一致；主题印花是否已清除。画板不是成品。
- 将来源标出的关键尺寸和印花占比写成目标比值，并在抽取图中测量可见物件的对应比值；注明透视或折叠造成的不可比项目。版型图和文字提示词互相矛盾时，先修正图像资产，再做重组测试。
- **符号图对照原设计**：每个槽位的图案类别、重复尺度与密度、颜色、原文案拼写、排布和印刷边界是否一致；有无新增标志或别的主题。配准印刷图还需核对整个载体宽高比、徽章占比及留白；图内正确不代表重组模型会遵守比例。
- 每张模型生成图记录来源图 ID、生成模型/版本、提示词、尺寸、版本、SHA-256、审核状态。失败图保留并标 `draft`；不得把它作为通过的产品事实。

## 两项重组验收

1. **基线复现**：只用已抽取的版型图、原始符号图、文字提示词与固定画面协议生图。对照原产品图、印花稿和刀模；本次生成不得再偷偷使用原图作为条件，否则另记为“原图辅助复现”。
2. **换符号不换产品**：主图沿用同一版型图、主图画面协议、模型与可固定设置，换成新符号图/文字；对照基线主图和新符号要求，检查印花槽外的物理形状、件数、材质表现、底色与构图。新副图保留同一产品版型及统一符号母稿，但按本次主题另定画面协议，不把旧副图场景作为重组目标。

Gen 的新主图先接受内部评分，再交用户审查。用户可要求修改；**未收到对当前主图版本的明确确认，不得设计或生成正式副图**。主图评分通过与用户确认是两个独立门槛。

记录参考图角色、路径/哈希、模型、分辨率、参数和种子（若支持）。纯文字、模型抽取图辅助、原图辅助、局部蒙版编辑分别记录，不能混算。保留目标图、生成图和来源 ID。没有原图或重组结果时记 `inconclusive`，不能报告还原率。

## 评分与门槛

**90% 指预先固定的人工核对表 ≥90/100，不等于像素相似度 90%。** 基线和换款分别评分。建议维度：物理结构/配件、几何与比例、印花槽位位置/面积/密度、固定材质与颜色、符号与精确文字、画面协议。每维 0–4 分，提前定总和为 100 的权重，再按 `Σ(权重 × 档位 / 4)` 折算；换款的不变项与新符号符合性分别记录。

- **硬门槛**：件数、实体轮廓、关键比例、印花区、精确文案错误，或符号替换时旧主题残留/非符号区域明显改变，直接失败。应在生图前列出每个必要符号类别及最低可见数量；漏掉预先列为关键的符号时按既定门槛处理，不在看图后临时提高标准。视觉图不能证明吸水性等材料性能。
- 要求主图“只换符号”时，保存同一版型上的印花区域蒙版或明确的区域边界，并比较基线与新主题主图的区域外变化；整图重新生成但画面看起来相似，不足以证明其余部分保持一致。新主题副图允许新场景和新排版，改查跨图产品一致性、画面目标、图片宣称证据及是否误用了旧副图构图。
- **目标**：抽取图通过逐项核对；基线复现 ≥90/100；换符号的不变项 ≥90/100 且新符号逐槽正确；两项均须通过硬门槛。
- **随机性**：有条件时同一配置至少观察 3 张，逐张记录，不能凭最佳一张宣称流程稳定达标。

`prompt.md` 中的每个相对路径都要能从文件所在目录解析到真实图片，且 MIME 与 SHA-256 匹配；这只证明交付数据一致，不证明图片内容复现正确。旧 [evaluation-record.schema.json](evaluation-record.schema.json) 只适用于历史单结果，可先用 Markdown 分别记录抽取、基线和换款的证据。
